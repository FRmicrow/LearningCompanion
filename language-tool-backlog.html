Epic 3
SRS Engine — Répétition Espacée
Moteur de répétition espacée (Anki-like) avec états New → Learning → Known → Mastered.
IDFeatureDescriptionTaille
F-301 Modèle de données SRS Ajouter les champs srsState, dueDate, interval, easeFactor à VocabularyEntry via migration GRDB. M
F-302 Algorithme SRS Implémenter l'algorithme SM-2 : intervalles 1j → 3j → 7j → 14j → 1m → 3m selon le rating (Easy / Good / Hard / Again). L
F-303 File de révision quotidienne Query GRDB pour récupérer les entrées dont dueDate ≤ today, triées par priorité. S
F-304 Rating persisted Persister le rating (Easy/Good/Hard/Again) et recalculer dueDate + easeFactor en temps réel. S

Learn & Review — Sessions de révision
Deux modes de révision : Learn (apprentissage guidé) et Review (flashcards).
IDFeatureDescriptionTaille
F-401 Vue Learn Afficher le mot, masquer la traduction, bouton Reveal, puis boutons Again / Hard / Good / Easy reliés au SRS Engine. M
F-402 Vue Review (flashcards) Afficher la traduction française, révéler l'anglais, noter Easy / Medium / Hard. M
F-403 Focus Session Mode "Today's Review" : enchaîner automatiquement toutes les cartes dues, avec compteur de progression (X / 18 cards). M
F-404 Indicateur de difficulté Afficher Easy / Medium / Hard comme sélecteur radio sur chaque carte pour contextualiser le mot. S
F-405 Métadonnées de révision Afficher "Last review: Yesterday" et "Next review: Tomorrow" en bas de chaque carte. S
